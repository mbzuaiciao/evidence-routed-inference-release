# Information availability benchmark

## Regimes

**A — Full information** supplies all numeric diagnostics and structured
provenance before routing. It measures degradation, unnecessary cost, and extra
abstention in a closed-world control.

**B — Budgeted observation** initially exposes returns summaries and a varying
subset of linear, squared-return, distribution, and stability evidence. Every
system sees the same explicit diagnostic prices and budget. Registered
conditions include returns-only, linear-only, distribution-only, conflicting
weak evidence, squared dependence hidden, and stability hidden.

**C — Open-world provenance** supplies returns and deterministic natural-
language research-process descriptions. Cases cover complete, incomplete,
hedged, conflicting, missing-failure, multi-market/window, unknown-dependence,
irrelevant, and prompt-injection-like prose. Instruction-like text is data, not
an instruction. Structured truth remains evaluator-only.

## Pairing and leakage controls

All six systems receive identical system-visible fingerprints for returns,
initial evidence, prose, allowed tools, budgets, method metadata, and inference
conventions. The conventions state the benchmark Sharpe and periodicity. Only
the evaluator-only oracle receives simulation truth. Provenance prose never
contains the hidden answer key. Information variants reuse the same return
draw; they do not create a new stochastic process family. The static router
cannot reveal hidden diagnostics. Adaptive systems can reveal only registered
groups and only until their budget is exhausted. Rejected, duplicate,
unnecessary, and budget-exhausted requests remain recorded.

The full-information condition materializes complete structured provenance
before routing. Rerunning an already visible diagnostic gains no evidence and
still counts as an unnecessary request with its configured cost.

Mock responses exercise serialization and orchestration. They are excluded
from scientific agent reasoning and can support only implementation claims.
